## 验收

- 1200 分的商品购买 3 件，行金额为 3600 分。
- 上述商品加运费 200 分，订单总额为 3800 分。
- 多个商品行各自计入数量，运费仅加一次。
- 订单汇总以商品行金额属性为唯一来源。
- 保持默认数量 1、空订单、生成器输入和非法输入校验。
