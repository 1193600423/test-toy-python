# 阶段 0：范围与验收记录

日期：2026-10-18。总体计划来自上层工作目录的 `docs/README.md` 第 4 节。

## 选择与范围

本项目是 `issue-agent` 的修复目标，不实现模型调用或工具循环。选择小型 Python 订单库，
是因为它没有第三方运行时依赖，测试快，整数金额、分页、数量汇总都能给出确定的业务结果。
三个任务是人工构造的开发案例，覆盖逻辑、边界、跨文件修复，不作为真实仓库修复能力的证明。

三条任务从同一个不可变提交独立开始。该基线同时含三个缺陷，验收只包括当前任务的隐藏测试和全部公开回归测试，
不要求一次修复另外两条任务。公开基础测试通过是环境和已有行为检查，不能替代 Issue 验收。
